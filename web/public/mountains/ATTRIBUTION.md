# Mountain photography — attribution

The hero parallax is built from two photographs published on Wikimedia Commons
under **CC BY-SA 4.0**. Both were cropped, keyed from their skies, colour-graded
and split into depth layers by `scripts/build-mountain-photos.py`; the adapted
files in this folder are therefore also licensed **CC BY-SA 4.0**.

| Layer files | Source | Author |
|---|---|---|
| `photo-sky`, `photo-peak` | [Sunset on AmaDablam.jpg](https://commons.wikimedia.org/wiki/File:Sunset_on_AmaDablam.jpg) | Ummidnp |
| `photo-mid`, `photo-near` | [Machapuchare Himal-3797.jpg](https://commons.wikimedia.org/wiki/File:Machapuchare_Himal-3797.jpg) | Bijay Chaurasia |

License text: https://creativecommons.org/licenses/by-sa/4.0/

The credit line rendered in the site footer satisfies the attribution
requirement; keep it if these files stay in use. To rebuild the layers from the
originals (or from different photographs), run the script with the two source
files as arguments.
